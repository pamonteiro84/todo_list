# ===========================================
# Banco de Dados: todo_list (Postgres)
# ===========================================

## 1. Conexão com o banco

- Usuário: paulo
- Host: localhost
- Porta: 5434 (ou outra que tenhas configurado)
- Banco: todo_list
- URL de conexão (para Rust / SeaORM):
  postgres://paulo:todo_db@localhost:5434/todo_list

- Comando psql:
  psql -U paulo -h localhost -p 5434 -d todo_list

- Lista de databases:
  \l

- Lista de roles (usuários):
  \du

---

## 2. Tabelas criadas pelas migrations

### Users
- id (UUID) PK
- name (string) NOT NULL
- email (string) NOT NULL UNIQUE
- password (string) NOT NULL
- created_at (timestamp) NOT NULL DEFAULT CURRENT_TIMESTAMP
- updated_at (timestamp) NOT NULL DEFAULT CURRENT_TIMESTAMP

### Todos
- id (integer) PK auto-increment
- user_id (UUID) NOT NULL → FK → users.id
- title (string) NOT NULL
- status (boolean) NOT NULL DEFAULT false
- due_date (timestamp) NULL
- created_at (timestamp) NOT NULL DEFAULT CURRENT_TIMESTAMP
- updated_at (timestamp) NOT NULL DEFAULT CURRENT_TIMESTAMP
- FK: fk-todos-user_id FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE

---

## 3. Comandos SQL úteis

- Listar tabelas:
  \dt

- Ver estrutura de uma tabela:
  \d users
  \d todos

- Criar database:
  CREATE DATABASE todo_list;

- Apagar database:
  DROP DATABASE todo_list;

- Criar role (usuário):
  CREATE ROLE paulo WITH LOGIN PASSWORD 'todo_db';

- Dar privilégios ao usuário:
  GRANT ALL PRIVILEGES ON DATABASE todo_list TO paulo;

- Conectar a database:
  \c todo_list

- Ver FKs:
  \d todos

---

## 4. SeaORM Migrations

- Rodar migrations pendentes:
  cargo run --package migration -- up

- Reset completo (apaga tabelas e reaplica todas):
  cargo run --package migration -- fresh

- Gerar entities a partir do DB:
  cargo make generate-entities

---

## 5. Makefile.toml (Cargo Make)

### Gerar entities
[tasks.generate-entities]
workspace = false
command = "sea-orm-cli"
args = ["generate", "entity", "-u", "${DB_URL}", "-o", "${ENTITIES_DIR}"]

### Rodar migrations
[tasks.run-migrations]
workspace = false
command = "cargo"
args = ["run", "--package", "migration", "--", "up"]

### Reset migrations
[tasks.run-migrations-fresh]
workspace = false
command = "cargo"
args = ["run", "--package", "migration", "--", "fresh"]

- Variáveis de ambiente no Makefile.toml:
[env]
DB_URL = "postgres://paulo:todo_db@localhost:5434/todo_list"
ENTITIES_DIR = "src/entities"

---

## 6. Verificações pós-migration

- Conectar ao DB:
  psql -U paulo -h localhost -p 5434 -d todo_list

- Verificar tabelas:
  \dt

- Ver colunas e FKs:
  \d users
  \d todos

- Confirmar dados (opcional):
  SELECT * FROM users;
  SELECT * FROM todos;

---

# Dica final

1. Sempre garantir que **users** é criada antes de **todos**, por causa da FK.
2. Se mudares tipos de ID, garante que PK e FK são compatíveis (integer vs uuid).
3. Use `cargo make run-migrations-fresh` quando precisares começar do zero.
